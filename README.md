# Agent IA de triage médical

POC d'un agent de triage médical pour le CHSA, basé sur Qwen3-1.7B, avec fine tuning SFT + LoRA et alignement DPO.

## Structure du projet

- `notebooks/` : notebooks d'exploration
- `scripts/` : logique réutilisable (extraction, traitement des données, entraînement)


## Commande utilisé 

uv add --dev ipykernel jupyterlab
